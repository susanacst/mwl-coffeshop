# ☕ Página Web en Construcción
Proyecto personal en desarrollo, diseñado como una práctica de frontend para simular la página de una marca de café.  
La idea es experimentar con diseño visual, estructura de contenido y funcionalidades típicas de una web de marca o tienda.

> 🚧 **Este sitio aún está en construcción.** Estoy trabajando en los estilos, estructura y diseño general como parte de mi aprendizaje y crecimiento como desarrolladora web.  
> Esta práctica tiene como objetivo mejorar mis habilidades en diseño web enfocado en marcas con una estética acogedora y profesional.

---

## 🎯 Objetivo del Proyecto

- Practicar diseño de interfaces modernas y atractivas  
- Simular una página oficial para una marca de café  
- Implementar componentes reutilizables  
- Desarrollar una estructura escalable para futuras funcionalidades

  ## ✨ Características Planeadas

- Página principal con bienvenida e imagen destacada  
- Secciones como:
  - Nuestra Historia  
  - Productos  
  - Ubicación / Contacto  
  - Blog / Recetas con café  
- Estilo visual cálido, elegante y amigable  
- Diseño responsive (para móviles y escritorio)

---

## 🛠 Tecnologías Utilizadas (hasta ahora)

- HTML5 + CSS3  
- JavaScript Vanilla  
- Organización modular en carpetas (`css`, `js`, `assets`)  
- Posible integración futura con frameworks (Vue, React)
